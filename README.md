# 🛒 E-commerce Sales Analysis 

This project uses **Python and Pandas** to analyze an e-commerce sales dataset. The notebook demonstrates data selection, filtering, sorting, grouping, and aggregation to identify sales trends and top-performing products and categories.

## Analysis Covered

* Dataset exploration and structure
* Data selection and filtering
* Sorting orders by sales and quantity
* Total and average sales
* Highest and lowest sales
* Total quantity sold
* Number of orders
* Category-wise sales analysis
* City-wise sales analysis
* Product-wise sales analysis
* Payment method analysis
* Top-performing products and categories
* Meaningful observations from the results

## Technologies Used

* Python 3
* Pandas
* Jupyter Notebook
